Subaru STARLINK Shortcuts

Lock, unlock, remote start and stop your Subaru from Siri, your watch, or a home screen widget. No app required.

Requires an active STARLINK subscription with the Security Plus option. Remote lock/unlock and remote start do not work without it.

What it asks for

Each shortcut prompts for four values when you install it:

ValueWhere it comes from
EmailYour MySubaru sign-in
PasswordYour MySubaru password
PINThe four-digit code you use for remote commands on the MySubaru site — not your password
Device IDA 13-digit number from your browser — see below

Finding your Device ID

This is the only value you have to dig for. It is the token MySubaru uses to recognise a trusted device, so it satisfies two-factor auth — you cannot make one up, and a fresh value will bounce you to the 2FA page instead of signing in.

  1. Open mysubaru.com with DevTools open on the Network tab.
  2. Log in.
  3. Select the login request.
  4. Open Payload (Chrome) or Request (Safari) and copy deviceId.

Earlier versions of these shortcuts also needed lastSelectedVehicleKey. That turned out to be unnecessary — sign-in works without it — so it is gone.

Security note. Anyone who picks up your unlocked phone can use the unlock shortcut to open your car. Consider requiring Face ID on it, or not installing it at all.
